Interaction notes
A
Copy as Python URLS list
One tuple per source URL, in the shape every verify_*.py already uses. On click → label swaps to ✓ Copied — N placements for 1.5s, then reverts. No toast.
URLS = [
    ("Adform 1", {88915001}, "https://…"),
]
The platform chips carry the same action scoped to one platform (.py on the chip), for cherry-picking a single vendor out of a mixed paste.
B
Per-row copy
Copies the raw value only, no quotes. On click → the label becomes ✓ copied for 1.5s; the row keeps its tint so the eye doesn't lose its place. Row order never changes.
C
Source, on hover
The cell shows the reference only — Sheet1!C14 or line 7. Hovering the row reveals the full line or cell it was pulled from, so a bad match is spottable without adding weight to every row.
Verify
Loads each Adform/CM360 URL for real and checks whether its own ID actually fires. Ad Manager rows aren't self-referential, so they're listed but skipped.
